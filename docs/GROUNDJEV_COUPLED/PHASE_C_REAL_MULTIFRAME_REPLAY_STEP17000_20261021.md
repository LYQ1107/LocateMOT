# Phase C：G2 真实多帧因果记忆回放（step 17000）

## 结论

这次回放验证了单主干耦合的真实运行边界：MOT20-03 TRAIN 的第 82–85 帧各只执行一次官方 G2 视觉编码；第 83–85 帧分别执行禁用记忆和上一帧记忆的 causal prefill，并复用了同一帧的视觉嵌入。没有加载第二个视觉模型。

记忆投影仍是未训练的 `IdentityMemoryTokenProjector`，因此该实验不构成跟踪或定位性能提升。后 3 帧中，记忆条件与无记忆条件的恢复框完全相同；相对于当前目标标注框的平均 IoU 均为 0.0000。该负结果说明下一步必须训练真实的 memory/projector 与 JEV 决策，而不是继续把未训练的记忆 token 当成性能改进。
