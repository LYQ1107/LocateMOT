# GroundJEV-MOT implemented architecture

Current real frame + task specification → native GroundAnything DLM proposals
and visual evidence → shared online decision core → global one-to-one matching
→ persistent physical identity memory → task-specific output filtering.

MOT/RMOT/OVMOT share decision weights and the identity schema. Task index,
expression and vocabulary condition the model; physical state is updated before
RMOT membership filtering. Evaluation GT and future frames never enter runtime
state. Missing detector confidence remains missing, not a fabricated probability.
All native proposals/parser-rejected frames follow the registered protocol.

## Persistent memory and global assignment

Hungarian matching uses structured scores with private NEW/IGNORE/NO_MATCH
columns and global competition. The shared core stores immutable birth anchor,
recent observation, reliability-held long memory, causal motion, physical lost
age,16-observation feature history, semantic counts, identity uncertainty and
lifecycle survival. Memory writes and identity errors affect later predictions;
GT never repairs a wrong history. Query rejection hides an output while its
physical identity state remains available to future frames.

State serialization preserves actual images/features/counters, including actual
zero-size rejected crops. New replay controls use full binary final state plus
complete decision traces; native sources may use exact FP32packed arrays with
all original JSON geometry/labels/scores/order retained. No quantization or
proposal deletion is implied. Fresh pipeline timers include actual archive/state/
render/video-encoder completion and final export; cached association FPS is
never called full native pipeline FPS.

Compact geometric retrieval now computes the original scalarIoU operation
order in FP64 batches and caches same-timestamp predicted boxes. Real dense
1397715pairIoUs,37groups32/64/128rankings and complete decisions/lifecycle/
metadata match the scalar reference exactly. This is an implementation speed
improvement, separate from the mixed16geometry+16appearance retrieval policy.

heads and the exact original NEW/IGNORE/NO_MATCH values and per-row probability
