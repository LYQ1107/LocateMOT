# G2 Clean independent held-out queue — 2026-10-20

The repository now contains a recoverable owner for the final G2/G0 held-out
comparison:

`scripts/groundjev/queue_g2_independent_heldout_eval.py`

It waits for the terminal Clean G2 receipt and the G2 deployment bundle, then
uses physical GPU7 to run both G0 (`GroundAnything-DLM`) and G2
(`GroundAnything-DLM-G2-CLEAN-V2`) with the same input manifests, official
GroundAnything parser, `tracking_dense` decoder, `empty_and_record` rejection
policy, Simple association tracker, and official multitask scorer. The G0
service is stopped before G2 starts, so the two services cannot change the
input or memory state of one another.

The registered scopes are:

- Refer-KITTI v2 sequence `0007`, single expression: 800 frames.
- Refer-KITTI v2 sequence `0007`, multi-instance expression: 800 frames.
- TAO-Amodal validation video `105` (`Making_a_sandwich...`): 40 annotation
  frames, with Base categories `baby`, `bowl`, `bun` and Novel category
  `shaker`.

The TAO scope is generated by
`scripts/groundjev/prepare_independent_ovmot_scope.py`. It uses fixed LVIS-v1
vocabulary (1,203 names), reads no evaluation labels at runtime, and reports
zero exact image overlap with the 583,251-row G2 Clean TRAIN manifest. The two
Refer-KITTI scopes also have zero exact image overlap in the streaming audit.

Runtime owner state:

`/data2/user/LocateMOT_GroundJEV/outputs/groundjev/heldout/g2_clean_independent_gpu7_v1/owner_state.json`

The OneJev four-GPU resume queue now waits for this owner to reach a terminal
state before claiming GPUs 4–7. A held-out failure is retained as evidence and
does not deadlock the main training queue; a successful owner records official
HOTA/DetA/AssA/IDF1/TETA metrics, rejected frames, output counts, and FPS for
both model identities.

No final held-out metric is claimed until the owner writes
`G2_CLEAN_FULL_INDEPENDENT_HELDOUT_COMPLETE` and its `comparison.json`.
