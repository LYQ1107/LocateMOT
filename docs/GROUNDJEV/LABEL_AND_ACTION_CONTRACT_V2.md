# Additive entity identity / proposal competition contract V2

V1 remains immutable. This contract applies only to A4 own-state experiments.
Every uniquely GT-supported proposal has the same positive entity target when its
correct confirmed live ID is available. Duplicate-proposal exclusivity is learned
separately by sparse competition/ranking, rather than declaring its entity invalid.
First effective NEW requires no previous confirmed birth and no unbound live ID;
prior annotation alone does not establish a predicted identity. Bind GT externally
at an actual predicted NEW with unique support even if another proposal won the
original Hungarian GT allocation. Never change the predicted identity or memory.
Unavailable retired/unbound IDs, ambiguous support and incomplete annotations stay
UNKNOWN. No unknown binding creates permanent-exit supervision. All live IDs are
scored; old Top-K remains a diagnostic. Background is never inferred from sparse
unmatched GT. The TRAIN audit covers1056frames/48051proposals and is stored in
outputs/groundjev/global_identity_v1/effective_birth_v2_audit.json.
